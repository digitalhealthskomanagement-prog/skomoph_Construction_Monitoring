## เป้าหมาย
ได้ "เทมเพลตเปล่า" ที่มีทุกระบบเหมือนเว็บ รพ.สรรคบุรี (รูปนำ · ปฏิทิน · ทรัพยากรทีม · S-Curve · รายงานอัปเดต · ความคืบหน้ารายเฟส · ล็อกอินด้วยรหัส) แต่ยังไม่มีข้อมูลใด ๆ — กรอกเองได้ทั้งหมดผ่านหน้าจอ

## ขั้นที่ 1 — คุณกด Remix (ทำเองก่อน 1 ครั้ง)
คลิกชื่อโครงการมุมซ้ายบน → Settings → "Remix this project" (หรือคลิกขวาที่การ์ดโครงการ → Remix) แล้วตั้งชื่อใหม่ เช่น "ระบบติดตามงานก่อสร้าง (เทมเพลต)". จากนั้นเปิดโปรเจคใหม่และสั่งงานผมในนั้น — โปรเจคใหม่จะได้ฐานข้อมูลของตัวเองแยกจากอันนี้ (เว็บ รพ.สรรคบุรี ไม่ถูกแตะต้อง)

หมายเหตุ: ผมสร้างโปรเจคใหม่แทนคุณไม่ได้ ต้องกด Remix เอง แต่หลังจากนั้นผมทำต่อให้ครบ

## ขั้นที่ 2 — ล้างข้อมูลให้เป็นระบบเปล่า (ในโปรเจคใหม่)
- ลบข้อมูลทั้งหมดใน phases, calendar_events, updates, risks และล้างรูปในที่เก็บไฟล์
- ตั้ง project_settings เป็นค่าเริ่มต้นว่าง: ชื่อโครงการ "—", ความคืบหน้า 0%, วันเริ่ม/สิ้นสุดปีปัจจุบัน
- เปลี่ยนรหัสเข้าระบบเป็นรหัสใหม่ของโปรเจคนั้น (คุณบอกตัวเลขที่ต้องการ ถ้าไม่บอกใช้ 11113 เดิม)

## ขั้นที่ 3 — ถอดข้อความ/รูปที่ผูกกับ รพ.สรรคบุรี ออก
- รูปนำ: เปลี่ยนเป็นพื้นที่ว่างมีปุ่ม "อัปโหลดรูปโครงการ" (ล็อกอินแล้วเปลี่ยนรูปได้เอง)
- หัวเว็บ/หัวข้อ/คำบรรยาย/ปีงบประมาณ: ดึงจากฐานข้อมูลแทนข้อความฝังในโค้ด
- หัวข้อกลุ่มเฟส: จาก "ขั้นเตรียมการ ก.ย.–ธ.ค. 2569 / การก่อสร้าง 16 งวด 730 วัน" → เป็นข้อความที่แก้ได้ในหน้าตั้งค่า
- ลิงก์ทรัพยากรทีม (Google Drive, NotebookLM): เปลี่ยนจากลิงก์ฝังโค้ด → รายการลิงก์ที่เพิ่ม/ลบ/แก้ได้เอง
- SEO/ชื่อหน้า/og image: ใช้ชื่อโครงการจากฐานข้อมูล
- ปฏิทินเริ่มที่เดือนปัจจุบัน (ไม่ fix ก.ค. 2569)

## ขั้นที่ 4 — หน้า "ตั้งค่าโครงการ" ใหม่ (เห็นเฉพาะเมื่อล็อกอิน)
`/settings` ประกอบด้วย
- ข้อมูลโครงการ: ชื่อ, คำบรรยาย, วันเริ่ม–สิ้นสุด, งบประมาณ, อัปโหลดรูปนำ
- จัดการเฟส: เพิ่ม/แก้/ลบ/เรียงลำดับ, เลือกหมวด (เตรียมการ/ก่อสร้าง), ใส่รหัสงวด, น้ำหนัก %, ป้ายระยะเวลา, สี
- จัดการลิงก์ทรัพยากรทีม
- ข้อความหัวกลุ่มทั้งสองหมวด
ปฏิทิน/รายงาน/ความเสี่ยง ยังเพิ่มจากหน้าเดิมได้เหมือนเดิม

## ขั้นที่ 5 — หน้าจอตอนยังว่าง (empty states)
ทุกส่วนแสดงข้อความชวนกรอกแทนกราฟว่าง เช่น "ยังไม่มีเฟสงาน — ไปที่ตั้งค่าเพื่อเพิ่ม", "ยังไม่มีกิจกรรมในปฏิทิน", "S-Curve จะแสดงเมื่อมีเฟสและปฏิทินแล้ว", "ยังไม่มีรายงาน"

## รายละเอียดทางเทคนิค
- Migration ใหม่ในโปรเจค remix: ตาราง `resource_links` (label, url, icon, order) + คอลัมน์ใน `project_settings` (`hero_image_path`, `prep_heading`, `prep_subtitle`, `cons_heading`, `cons_subtitle`) พร้อม GRANT + RLS (อ่านสาธารณะ, เขียนผ่าน server function ที่ผ่าน gate)
- เพิ่ม server functions: `savePhase`/`deletePhase`/`reorderPhases`, `saveSettings`, `createHeroImageUpload`, `saveResourceLink`/`deleteResourceLink` ใน `src/lib/data.functions.ts` (ผ่าน gate เดียวกับของเดิม)
- รูปนำเปลี่ยนจาก asset ฝังโค้ด → signed URL จากที่เก็บไฟล์ พร้อม fallback เป็นพื้นหลัง gradient เมื่อยังไม่มีรูป
- คงสถาปัตยกรรมเดิม: TanStack Start + ปฏิทิน/สูตร S-Curve/ระบบบีบอัดรูปหลายไฟล์ ใช้ซ้ำได้ทั้งหมด
- แก้ hydration mismatch ที่พบในหน้าอัปเดต (วันที่/signed URL ต่างกันระหว่างเซิร์ฟเวอร์-เบราว์เซอร์) ไปพร้อมกัน

## ผลลัพธ์
โปรเจค remix นี้ใช้เป็นต้นแบบได้ตลอด: ทุกครั้งที่มีงานก่อสร้างใหม่ในจังหวัด กด Remix จากเทมเพลตนี้ → ล็อกอิน → กรอกในหน้าตั้งค่า → ใช้งานได้ทันที (1 โครงการ = 1 เว็บ = 1 ฐานข้อมูล แยกกันชัดเจน)
